# Bevel Language Support

Поддержка языка программирования Bevel (`.bv`) версии 0.1 для Visual Studio Code.

## Возможности
- Подсветка синтаксиса для всех ключевых слов, типов и директив компилятора согласно спецификации v0.1.
- Фирменная иконка для файлов `.bv` в проводнике файлов.
- Поддержка однострочных (`//`) и блочных (`/* */`) комментариев.

## Установка
1. Откройте эту папку в VS Code.
2. Нажмите `F5` для запуска в режиме отладки (откроется новое окно Extension Development Host).
3. Создайте или откройте файл с расширением `.bv`, чтобы проверить подсветку.
